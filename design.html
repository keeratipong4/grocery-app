14 · Do's & Don'ts

✅ Do

  • Use bg-green-600 for every purchase action: Add to Cart, Checkout, Shop Now, Membership Submit.
  • Use amber #F4B223 for all navigation/browse actions.
  • Render DiscountBadge only when discount > 0.
  • Format all prices through formatPrice(). Never raw numbers.
  • Use rounded-card (10px) on ProductCard/BrandCard; rounded-banner (12px) on panels/hero.
  • Test every component at 375px viewport before marking task done.

❌ Don't

  • Don't install UI libraries (shadcn, MUI, Chakra). Tailwind only.
  • Don't use bg-success (#3BAE5A) for purchase buttons — that's for status text and New badge only.
  • Don't add inline styles except for category.color on CategoryCard icon circles.
  • Don't hardcode product/category data inside components — always import from src/data/.
  • Don't use any in TypeScript — strict mode is on.
  • Don't render the strikethrough original price when discount === 0.
